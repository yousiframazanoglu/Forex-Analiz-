Proje Hakkinda

ForexAnaliz Nedir?

ForexAnaliz, Internet Tabanli Programlama dersi kapsaminda gelistirilmis bir egitim web platformudur.

Platform; gercek zamanli kur verileri, Japon mumu chart, ekonomik takvim, tam kullanici sistemi ve iletisim formu icermektedir.

Kur verileri ExchangeRate-API ve Frankfurter API uzerinden, kullanici sistemi Python FastAPI + SQLite ile saglanmaktadir.

Teknik Altyapi

HTML5 + CSS3 + Vanilla JS
Python FastAPI + SQLite backend
WebSocket ile canli kur akisi
Canvas tabanlı Japon mumu chart
JWT auth + Gmail SMTP
ExchangeRate-API + Frankfurter API
